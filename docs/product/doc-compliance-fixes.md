# 文档符合性修复计划

> 创建于：2026-03-14
> 来源：对照交接包文档与当前实现的差异分析

---

## 背景

对照 `CLAUDE交接包/docs/` 全部文档及原型 HTML（v4），梳理出 5 项当前实现与文档要求不符之处。

---

## 不符项清单

### 不符项 1：缺少"人数"和"AI回合"字段（影响列表页 + 详情页）

**文档依据：**
- 验收清单：`8–12 岁 / L1 / 第 1 课 / 45 分钟 / 4–6 人 / 3 个 AI 回合`
- 原型 v4 列表页卡片底部：`L1｜45 分钟｜4–6 人线下小班｜3 个 AI 回合｜已按规范接入`
- 原型 v4 详情页课次 pills：`45 分钟` / `4–6 人线下小班` / `3 个 AI 回合`

**当前缺失：** 数据库 Lesson 表无 `groupSize`、`aiRoundsCount` 字段，两页均无对应显示。

**修复方案：**
1. Lesson 表新增 `groupSize String?` 和 `aiRoundsCount Int?`
2. 执行数据库迁移
3. seed.ts 补充：`groupSize: "4-6"`，`aiRoundsCount: 3`
4. 详情页：pills 改为「时长 / 人数+模式 / AI回合」
5. 列表页 PackageGrid：底部补充人数与AI回合

---

### 不符项 2：Sidebar 有无效菜单链接

**文档依据：** 功能需求清单未要求「我的课程包」「教师中心」「系统设置」

**当前问题：** 点击这三个链接返回 404

**修复方案：** Sidebar 导航只保留「课程包列表」

---

### 不符项 3：搜索/筛选是静态 UI

**文档依据：** 功能需求清单：「筛选与搜索课程包」

**当前问题：** 搜索框和筛选器输入后无任何效果，API 已支持但前端未接入

**修复方案：** 使用 URL searchParams，列表页读取参数传给 Prisma 查询，筛选器为 Client Component

---

### 不符项 4：TopBar 有无效导航链接

**文档依据：** 同不符项 2，功能需求未要求这些页面

**当前问题：** TopBar defaultTabs 包含三个无效链接

**修复方案：** defaultTabs 只保留「课程包列表」

---

### 不符项 5：管理员后台无 admin 角色校验

**文档依据：** 管理员端功能仅供管理员使用

**当前问题：** 任意已登录用户（含普通教师）均可访问 `/admin`

**修复方案：** admin/page.tsx 增加 role 校验，非 admin 重定向至 `/`

---
