# 课程生成系统分层生成规则矩阵 v1

## 一、文档定位

本矩阵用于把四层基线真正合并成系统可执行的生成规则：

- 年龄段基线
- 难度基线
- 课程组织形态基线
- 产出物形态基线

它解决的问题是：

**当系统选择了某个年龄段和难度后，应该优先生成什么样的课程，不该生成什么样的课程。**

---

## 二、四层变量

### 1. 年龄段
- A1：6–7 岁
- A2：8–9 岁
- A3：10–12 岁
- A4：13–15 岁

### 2. 难度
- L1：AI 启蒙使用
- L2：AI 基础应用
- L3：AI 结构化创作
- L4：AI 多轮协作与优化

### 3. 组织形态
- S1：单课闭环型
- S2：系列项目型

### 4. 产出物形态
- P1：档案类
- P2：计划类
- P3：故事类
- P4：空间类
- P5：发布类
- P6：图片类
- P7：漫画类
- P8：音乐类
- P9：动画类
- P10：游戏类
- P11：互动展示类

---

## 三、总规则

### 1. 年龄段与组织形态的默认关系
- A1 / A2 优先配 S1 单课闭环型
- A3 以 S1 为主，部分开放 S2 轻项目型
- A4 可明显开放 S2 系列项目型

### 2. 年龄段与难度的默认关系
- A1：优先 L1，少量 L2
- A2：优先 L1 / L2，少量低配 L3
- A3：优先 L2 / L3，少量 L1，部分 L4
- A4：优先 L3 / L4，也可用 L2

### 3. 产出物的默认优先级
- 低龄优先：档案、图片、轻计划、轻故事
- 中段优先：计划、故事、空间、发布、漫画
- 高段优先：发布、空间、图片、音乐、动画、游戏、互动展示

## 四、年龄段 × 难度主矩阵

| 年龄段 \ 难度 | L1 | L2 | L3 | L4 |
|---|---|---|---|---|
| A1 6–7岁 | 强开放 | 有条件开放 | 不建议 | 禁用 |
| A2 8–9岁 | 强开放 | 强开放 | 有条件开放 | 禁用 |
| A3 10–12岁 | 可开放 | 强开放 | 强开放 | 有条件开放 |
| A4 13–15岁 | 可开放 | 可开放 | 强开放 | 强开放 |

**解释：**
- 强开放：系统可默认生成
- 有条件开放：可生成，但要自动降复杂度或加限制
- 不建议：默认不生成，除非人工指定
- 禁用：系统默认禁止

## 九、系统生成时的优先组合

### 1. A1 + L1
默认推荐：
- S1 单课闭环型
- P1 档案类
- P6 图片类
- 轻量 P3 故事类

不推荐：
- 空间类重整合
- 发布类重筛选
- 动画 / 互动展示 / 重游戏

### 2. A2 + L2
默认推荐：
- S1 单课闭环型
- P2 计划类
- P3 故事类
- P6 图片类
- P7 漫画类
- 轻量 P5 发布类

### 3. A3 + L3
默认推荐：
- S1 或轻量 S2
- P2 计划类
- P3 故事类
- P4 空间类
- P5 发布类
- P6 图片类
- P7 漫画类
- P8 音乐类

### 4. A4 + L4
默认推荐：
- S2 系列项目型优先
- P5 发布类

- P9 动画类
- P10 游戏类
- P11 互动展示类

## 十、系统禁用规则

### 明确禁用
- A1 + L4
- A1 + S2
- A1 + P9 / P11
- L1 + S2
- L1 + P9 / P10 / P11
- A2 + L4

### 默认不推荐
- A1 做复杂空间整合
- A2 做多轮优化型发布项目
- A3 默认重动画大项目
- A4 默认低幼档案类单页为主成果

## 十一、样板主线映射参考

《我的神奇搭档创作计划》当前更适合被系统理解为：

- 年龄段：**A3 为主**
- 难度：**L1 / L2 起步，逐步到 L3**
- 组织形态：**S1 单课闭环型系列**
- 产出物：**P1 / P2 / P3 / P4 / P5 为主**

这说明它非常适合作为：
- 首发样板
- 系统训练样例
- 中段主力课程模板

---

## 十二、阶段性结论

做到这一步，课程生成系统已经具备“分层生成”的基本框架：

- 不是随便生成
- 而是按年龄、难度、组织形态、产出物四层共同约束生成

这会明显减少：
- 年龄不匹配
- 难度错位
- 产出物跑偏
- 课程结构失真

---

## 十三、使用建议

这份矩阵应作为课程生成系统的**总控规则层**使用。系统实际生成课程时，建议采用如下顺序：

1. 先读取年龄段基线，确定语言、抽象程度、教师引导强度
2. 再读取难度基线，确定 AI 使用深度与任务复杂度
3. 再读取课程组织形态基线，确定单课闭环还是项目推进
4. 再读取产出物形态基线，确定默认作品类型
5. 最后用本矩阵进行组合校验，过滤掉不适合或禁用的组合
