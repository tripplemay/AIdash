# 主要页面实现要求与参考图映射

## 页面 1：登录页
### 结构要求
- 左侧品牌介绍与主视觉
- 右侧登录窗口
- 保留原有交互逻辑
- 登录字段为账号、密码
- 预留企业微信登录、微信登录按钮

### 视觉要求
- 采用浅蓝紫雾光科技感
- 左侧主视觉占比更大
- 右侧表单卡片白色/浅透明
- 整体轻盈、通透

### 参考图
- `assets/01_首页参考图_品牌展陈型.png`

## 页面 2：课程包列表页
### 结构要求
- 左侧轻量导航
- 左侧“课程包”承担课程结构入口，不再在右侧重复做导航
- 右侧为课程包列表主区
- 列表页当前第一个课程包必须为《我的神奇搭档课程包》真实内容

### 视觉要求
- 侧栏收窄
- 菜单项更紧凑
- 保持浅蓝紫雾光科技感
- 课程卡片圆角大、边框轻、信息清晰

### 参考图
- `assets/02_课程包列表页参考图.png`

## 页面 3：课程包详情页
### 结构要求
- 展示课程包主图、简介、适用年龄、级别、课次列表
- 点击“进入本课”后直接进入已确认原型页

### 视觉要求
- 统一系统壳层下强化课程主题感
- 主图必须用最终确认图
- 详情信息结构清楚，不要做成复杂后台页

### 必须使用的图片
- `assets/03_我的神奇搭档课程包主图_最终确认版.png`

## 页面 4：已确认原型页承载
### 结构要求
- 进入本课后直接进入
- 不再设置独立接入中间页
- 保证链路稳定
