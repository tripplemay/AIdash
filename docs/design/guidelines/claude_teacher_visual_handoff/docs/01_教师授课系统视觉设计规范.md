# 教师授课系统视觉设计规范

## 1. 系统定位
本系统是面向老师使用的 **教师授课系统**，不是课程研发系统，也不是对外官网。

## 2. 整体视觉基调
核心关键词：
- 浅蓝紫雾光科技感
- 高亮度
- 轻科技
- 通透
- 教师友好
- 现代、整洁、可信

明确避免：
- 深色科幻
- 重霓虹夜景感
- 过度游戏化
- 厚重后台风

## 3. 色彩系统
建议主色与语义色按以下范围实现：

### 主色
- 主蓝：#7F98FF ~ #8AA8FF
- 雾光紫：#9B9CFF ~ #A8B2FF
- 青蓝高光：#7FD7FF ~ #8DE0FF

### 背景色
- 页面底色：#F5F7FF
- 容器底色：#FFFFFF / 带轻微透明白
- 浅层背景：#FBFCFF
- 功能区底色：#EEF3FF

### 文本色
- 一级标题：#4C5F97
- 二级标题：#52639E
- 正文主色：#5F73A8
- 辅助文字：#7B8DBF
- 弱提示：#9AA7CC

### 语义色
- 成功：#4FAE74 附近
- 警示：#F1B24A 附近
- 风险：#D96C76 附近
- 中性边框：#E4EAFF ~ #E8EDFF

## 4. 材质与氛围
- 使用大面积浅色背景与轻雾化渐变
- 可使用极轻的蓝紫发光、柔和高光、淡淡漂浮几何元素
- 卡片可有轻玻璃感，但不能太强
- 阴影要软、浅、散，不要硬阴影

## 5. 圆角与阴影
- 主容器圆角：24px ~ 32px
- 普通卡片圆角：18px ~ 24px
- 输入框 / 按钮圆角：14px ~ 999px
- 阴影建议：`0 12px 30px rgba(110,130,190,0.08)` 量级

## 6. 字体与层级
建议使用中文无衬线体系，风格要求：
- 平直、现代、科技感轻微
- 不要幼稚卡通字感
- 不要传统黑体/楷体气质

层级建议：
- 系统大标题：40~64px / 700~800
- 页面标题：30~40px / 700~800
- 卡片标题：20~24px / 700~800
- 正文：14~16px / 400~500
- 辅助信息：12~14px / 400~500

## 7. 按钮规范
### 主按钮
- 胶囊型
- 蓝到青的轻渐变
- 用于“登录”“进入详情”“确认进入下一阶段”等主动作

### 次按钮
- 白底浅边框
- 保持轻感
- 不可做成厚重灰按钮

### 风险按钮
- 仅用于暂停 / 废弃 / 删除等动作
- 颜色要轻，不要大片高饱和红

## 8. 表单规范
- 输入框高度建议 46~54px
- 背景以白色或极浅蓝白为主
- 边框细浅
- 占位提示语弱化
- 不要做成后台管理系统那种硬边框表单

## 9. 导航规范
### 顶部导航
- 轻量
- 白底或极浅透明底
- 不宜过厚

### 左侧导航
- 必须更轻、更窄、更紧凑
- 不可过宽
- 用户信息卡要缩小
- 菜单项高度压缩
- 菜单间距收紧
- 版权区上移

## 10. 页面级设计原则
### 登录页
- 左侧品牌介绍与主视觉
- 右侧登录窗口
- 登录字段为账号、密码
- 必须预留企业微信 / 微信登录按钮

### 课程包列表页
- 沿用首页浅蓝紫雾光科技感
- 左侧为系统导航与课程结构入口
- 右侧只保留课程包列表内容
- 不能出现右侧重复导航

### 课程包详情页
- 在统一系统壳层下，引入课程主题主图与课程信息
- 视觉上要体现“进入这门课”
- 但不能破坏系统统一感

### 进入本课后
- 直接进入已确认原型页
- 不再经过单独接入中间页

## 11. 强约束内容
### 《我的神奇搭档课程包》
列表页第一个课程包必须使用真实内容：
- 适用年龄：8–12 岁
- 第 1 课：《我的神奇搭档》
- 本课成果：《我的神奇搭档介绍页》
- L1
- 45 分钟
- 4–6 人线下小班
- 3 个 AI 回合
- 已按规范接入

### 课程包详情主图
必须严格使用已确认最终版本：
- 蓝色大机器人
- 绿色小机器人
- 一个男孩与机器人握手互动
- 左上角“样板课”标识
- 标题为《我的神奇搭档课程包》
- 整体更卡通，适合 8–12 岁
- 机器人搭档形象必须与网站首页机器人不同
