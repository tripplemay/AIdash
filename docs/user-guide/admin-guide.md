## 基础功能（与教师相同）

## 1. 登录系统

1. 打开系统网址，进入登录页
2. 在「账号」栏输入您的用户名
3. 在「密码」栏输入密码
4. 点击「登录」按钮

登录成功后自动跳转到课程包列表页。

**如果登录失败**：页面会提示"账号或密码错误，请重试"。请检查用户名和密码是否正确。

> 管理员账号由系统初始化创建，不通过邀请码注册。

---

## 2. 浏览课程包

登录后进入**课程包列表页**，以卡片网格形式展示所有已发布的课程包。

每张课程包卡片展示：

- **封面图**：课程包主图
- **年龄段 · 难度**标签（右上角）
- **课程包名称**
- **课程概要**：适用年龄、第一课标题、本课成果
- **底部信息**：难度 · 时长 · 人数 · AI 回合数

点击卡片上的「进入详情」按钮，进入该课程包的详情页。

---

## 3. 筛选与搜索

### 按年龄段和难度筛选

在左侧边栏「课程包列表」下方，有一个可展开的**筛选树**：

1. 点击「课程包列表」菜单项，展开筛选树
2. 点击某个年龄段（如"A2｜8-9岁 基础段"），筛选出该年龄段的课程包
3. 进一步点击年龄段下方的难度等级，做二级筛选
4. 点击「全部课程」回到无筛选状态

筛选条件会自动记住，下次打开系统仍然保持。

---

## 4. 查看课程包详情

在课程包详情页，您可以了解课程包的完整信息：

- **课程包信息**：封面大图、名称、简介、四项元数据
- **课次列表**：每条课次的编号、标题、时长、人数、AI 回合数、本课成果
- 课次右侧有「进入本课」按钮，未接入的课次显示灰色"未接入"

页面顶部有「← 返回课程包列表」链接。

---

## 5. 进入单课授课

点击「进入本课」后进入单课渲染页面：

- **顶部导航栏**：返回链接 + 课次标题 + 打印按钮 + 进度条
- **左侧目录导航**：固定面板，自动高亮当前阅读环节
- **右侧课程内容**：课次信息卡 + 各教学环节（文本、引用、列表、AI 模板、信息框、网格、折叠、问答）
- **课次间导航**：左侧边栏底部显示所有课次，可直接跳转

---

## 6. 课堂辅助功能

- **一键复制 AI 模板**：点击模板块右上角复制按钮
- **打印课程**：点击「打印本课」按钮，自动优化打印排版

---

## 7. 问 AI 对话

点击左侧边栏的「问AI」进入对话页面。所有角色均可使用。

### 界面布局

页面分为左右两栏：
- **左侧对话列表**（280px）：显示所有对话，按最近更新排序
- **右侧对话区域**：消息展示 + 输入框

### 新建对话

1. 点击对话列表顶部的「新建对话」按钮
2. 弹窗中选择对话模式：
   - **通用模式**：通用 AI 助手，可以回答任何问题
   - **课程设计模式**：AI 具备课程设计专业知识，适合课程规划和设计咨询
3. 点击即创建对话并进入

### 发送消息

1. 在底部输入框中输入消息
2. 按 Enter 发送（Shift+Enter 换行）
3. AI 以流式方式实时输出回复，显示脉动蓝点表示正在生成
4. 生成期间输入框禁用，生成完毕后可继续对话

AI 回复支持 Markdown 格式，包括标题、列表、代码块、表格等。

### 联网搜索

AI 会自动判断是否需要联网搜索最新信息。搜索结果以 [1]、[2] 等引用标注展示在回答中，底部附来源链接。

### 复制 AI 回复

AI 回复消息右下角有「复制」按钮，点击可复制完整回复内容。

### 管理对话

- **切换对话**：点击左侧对话列表中的任意对话
- **对话标题**：首轮对话后 AI 自动生成标题（10 字以内）
- **删除对话**：点击对话项右侧的 × 按钮，3 秒内再次点击确认删除
- 对话列表中每条对话显示标题、模式标签（通用/课设）和更新时间

## 8. 个人资料

点击右上角**头像** → 选择「个人资料」进入资料页。

- 可修改：**姓名**、**邮箱**（选填）、**手机**（选填）、**部门**（选填）
- 点击头像区域可从 **60 个预设卡通头像**中选择
- 点击「修改密码」按钮可修改密码（输入当前密码 → 新密码至少 6 位 → 确认）
- 退出登录：点击右上角头像 → 选择「退出登录」

## 课程研发模块（与教学主管相同）

## 9. 课程研发概述

课程研发模块用于在系统内完成课程设计全流程：

```
新建项目 → 填写方向信息 → AI 生成框架 → 审阅/修改 → 确认框架
    → 逐课生成详细方案 → 逐课修订 → AI 审核 → 定稿 → 发布
```

点击左侧边栏「课程研发」进入研发进度看板，以手风琴布局按状态分组展示项目。

---

## 10. 新建研发项目

在研发进度看板中，点击「+ 新建项目」按钮，自动创建新项目并进入方向确认页。

---

## 11. 方向确认与框架生成

### 填写课程信息

方向确认页分四个区域：

- **课程定位**（必填）：年龄段、难度级别、课程方向、项目标题（可 AI 生成）
- **课程结构**：课程组织形态、预计课次数、产出物形态和名称
- **视觉风格**：图片风格（预设或自定义）
- **补充信息（选填）**：大致框架、核心诉求标签、补充约束标签

### 生成框架

填写完信息后点击「生成课程框架」，AI 流式生成框架和封面图。可在右侧面板输入修改意见让 AI 调整，反复迭代直到满意。

### 确认框架

满意后确认框架，系统自动创建方案骨架，进入工作台。

---

## 12. 工作台：课次方案打磨

工作台是课程研发的核心工作区：

- **生成课次方案**：点击课次卡片上的「生成」按钮，AI 流式生成详细方案（含 7 个板块）
- **修改课次方案**：点击预览中的板块/图片 → 底部弹出输入栏 → 输入修改意见 → AI 局部调整
- **重新生成课次**：整体重做某个课次
- **重新生成图片**：点击图片单独重新生成
- **分页加载**：课次多时点击「加载更多」
- **保存版本**：点击顶部「保存版本」保存快照
- **AI 使用统计**：查看总费用、调用次数、每课均价

---

## 13. 审核与定稿

1. 所有课次方案生成完毕后，点击「审核并定稿」
2. AI 进行 10 项基线校验（目标清晰度、AI 价值、时间分配、卡点充分性等）
3. 审核通过后自动定稿，方案锁定

**撤回定稿**：点击「撤回定稿」解锁方案继续修改。已发布的课程包不受影响。

---

## 14. 发布到课程库

定稿后页面底部出现发布面板：

1. 确认课程包标题（可修改）
2. 可选填简介
3. 点击「发布」
4. 课程包立即出现在教师端列表

---

## 15. 管理研发项目

- **废弃**：点击顶部「废弃」按钮
- **删除**：在看板中点击项目卡片的「删除」按钮

## 管理后台

## 16. 课程包管理

点击「管理后台」→「课程包管理」。

### 课程包列表

表格展示所有课程包（含草稿和已下线），包括：名称、Slug、年龄段、级别、状态、课次数。

### 编辑课程包

点击「编辑」→ 弹窗修改标题、年龄段、级别 → 点击「保存」。

### 上线/下线

- 「下线」：教师端不再显示
- 「上线」：恢复教师可见

### 删除课程包

点击「删除」→ 确认弹窗 → 删除数据库记录（不可撤销）。

---

## 17. 用户管理

点击「管理后台」→「用户管理」。

### 用户列表

表格展示所有用户：姓名、用户名、角色、创建时间。

### 新建用户

1. 点击顶部「新建用户」按钮
2. 填写表单：
   - **姓名**（必填）
   - **用户名**（必填，登录用，创建后不可修改）
   - **角色**：选择 老师 / 研发员 / 管理员
   - **密码**（必填）
3. 点击「创建」

如果用户名已存在，系统会提示错误。

### 编辑用户

1. 点击用户行的「编辑」按钮
2. 可修改姓名和角色
3. 点击「保存」

> 注意：将研发员降级为老师时，系统会提示该用户进行中的研发项目将无法被访问。

### 重置密码

1. 点击用户行的「重置密码」按钮
2. 输入新密码（至少 6 位）
3. 点击「重置」

### 删除用户

点击「删除」→ 确认弹窗 → 删除。

> 注意：不可删除自己的账号。

### 部门管理

点击用户管理页顶部的「部门管理」按钮，弹出部门管理弹窗：

- **添加部门**：输入部门名称，点击「添加」
- **编辑部门**：点击部门行的「编辑」按钮，修改名称后点击「保存」
- **删除部门**：点击「删除」按钮，确认后删除

部门创建后，用户可以在个人资料页选择所属部门。

### 邀请码管理

点击用户管理页顶部的「邀请码管理」按钮，弹出邀请码管理弹窗：

**生成邀请码**：

1. 设置**最大使用次数**（默认 10 次）
2. 选择**有效期**（7 天 / 30 天 / 90 天）
3. 点击「生成」

**管理已有邀请码**：

每个邀请码显示：
- 邀请码字符串 + 「复制」按钮
- 状态：有效（绿色）/ 已禁用 / 已过期 / 已用完
- 使用次数：如"3/10 次"
- 到期时间

可执行操作：
- **禁用/启用**：临时停用或恢复某个邀请码
- **删除**：永久删除邀请码

新用户使用邀请码注册后默认为「研发员」角色，管理员可在用户管理中修改角色。

## 18. AI 服务配置

点击「管理后台」→「AI 服务配置」。

### AI 服务提供商管理

#### 添加提供商

1. 点击「+ 添加」按钮
2. 填写表单：
   - **名称**：如"OpenRouter"
   - **API 地址**：如 `https://openrouter.ai/api/v1`
   - **API Key**：填入服务商提供的密钥（加密存储，前端只显示掩码）
   - **代理地址**（可选）：如 `socks5://127.0.0.1:1080`，留空表示直连
3. 勾选支持文本生成 / 支持图片生成
4. 点击保存

系统会自动清理 API 地址中误填的子路径和末尾斜杠。

#### 测试连接

保存后可点击测试按钮，验证提供商的 API 是否可用。

#### 编辑/删除提供商

直接在提供商卡片上修改信息或删除。

### 动作→模型映射

系统定义了 10 个 AI 动作，需要为每个动作配置使用的提供商和模型：

**文本动作（7 个）**：

| 动作 | 说明 |
|------|------|
| 生成课程框架 | 根据方向信息生成课程框架 |
| 调整框架 | 根据修改意见调整框架 |
| 生成/重新生成课次 | 生成课次详细方案 |
| 按意见修改课次 | 根据修改意见调整课次 |
| 单字段改写 | 改写课次方案中的单个字段 |
| 课次审核 | 定稿前的 AI 质量检查 |
| AI 对话 | 问 AI 模块使用的模型 |

**图片动作（3 个）**：

| 动作 | 说明 |
|------|------|
| 课次封面图 | 生成课次 hero 图片 |
| 课内插图 | 生成课次内的插图 |
| 课程包封面图 | 生成课程包封面 |

#### 配置步骤

1. 选择提供商
2. 从该提供商的模型列表中搜索选择模型
3. 文本模型：输入价格会自动获取（也可手动覆盖）
4. 图片模型：需手动输入单次调用价格（支持 USD 或 CNY）
5. 保存前系统会自动测试模型可用性（图片模型跳过测试）

### AI 用量统计

页面底部展示 AI 调用统计：

- 按模型 / 按动作类型分组
- 支持时间范围筛选：今日 / 本周 / 本月 / 全部
- 显示调用次数、token 数、总费用
- 显示当前 USD→CNY 汇率

#### 刷新价格

点击「刷新定价」按钮，系统会从提供商 API 重新获取模型价格。

## 19. Prompt 配置

点击「管理后台」→「Prompt 配置」。包含三个标签页。

### 基线管理

基线是 AI 生成课程时参考的设计规则和约束，共 23 条，按维度分类：

| 维度 | 数量 | 说明 |
|------|------|------|
| 通用 | 1 | 所有课程通用的设计原则 |
| 年龄段 | 4 | A1~A4，按年龄段的教学要求 |
| 难度 | 4 | L1~L4，按难度的内容深度 |
| 组织形态 | 2 | S1~S2，线下小班/大班等 |
| 产出物 | 11 | P1~P11，不同产出物类型的要求 |
| 矩阵 | 1 | 跨维度规则 |

**编辑基线**：

1. 左侧按维度分类浏览，点击选中一条基线
2. 右侧编辑器修改内容
3. 点击「保存」

**版本管理**：

- 每次保存自动创建新版本
- 点击「版本历史」查看所有历史版本
- 可以查看两个版本之间的逐行 diff 对比
- 点击回滚可恢复到任意历史版本

> AI 生成课程时，系统会根据项目属性（年龄段、难度等）自动匹配对应维度的基线，只注入相关内容。

### 提示词模板

6 个 AI 动作的 Prompt 模板，支持 28 个预定义变量（`{{变量名}}` 格式）。

**编辑模板**：

1. 左侧选择动作（如"生成课程框架"）
2. 右侧编辑器修改模板内容
3. 需要插入变量时，从变量面板点击变量名自动插入
4. 点击「保存」

**变量分组**：

| 分组 | 变量示例 |
|------|---------|
| 项目信息 | `{{projectTitle}}`、`{{courseDirection}}` |
| 课程属性 | `{{ageRange}}`、`{{ageLabel}}`、`{{level}}` |
| 学员特征 | `{{orgForm}}`、`{{deliverableType}}` |
| 基线内容 | `{{baselineContent}}`（自动拼装） |
| 用户输入 | `{{userFeedback}}` |

版本管理方式与基线管理相同（版本历史 + diff + 回滚）。

> 如果 DB 中没有模板，系统会使用内置的默认模板，不会影响功能。

### 预设管理

管理课程研发表单中的下拉选项和标签：

| 分类 | 说明 |
|------|------|
| 课程方向 | 预设的课程方向选项 |
| 图片风格 | 图片生成风格预设 |
| 图片构图引导 | 图片构图约束（如安全裁切区） |
| 核心诉求标签 | 可点选的需求标签 |
| 补充约束标签 | 可点选的约束标签 |

**操作**：

- 左侧切换分类，右侧管理该分类下的预设
- 点击「+ 新增」添加新预设
- 点击预设项可编辑名称和值
- 拖拽可调整排序
- 点击「删除」移除预设

## 20. AI 调用记录

点击「管理后台」→「AI 调用记录」。

### 查看记录

分页展示所有 AI API 调用记录（每页 20 条）：

- **筛选条件**：按项目、动作类型、时间范围（今日/本周/本月/全部）
- **列表信息**：项目名、动作类型、模型、输入/输出 token、费用、时间
- **详情查看**：点击展开可查看完整的 System Prompt 和 User Message

> 作为管理员，您可以看到所有用户的调用记录。

### 清理旧日志

1. 点击顶部「清理旧日志」按钮

## 22. 常见问题

### 用户管理

**Q：创建用户时提示"用户名已存在"？**
A：用户名是唯一标识，不可重复。请使用其他用户名。

**Q：可以修改用户名吗？**
A：不可以。用户名在创建后不可修改，作为登录凭证使用。

**Q：为什么不能删除自己的账号？**
A：系统安全机制，防止管理员误删自身导致无法管理系统。

### AI 服务配置

**Q：添加提供商后测试失败？**
A：请检查：
1. API 地址是否正确（不要包含 `/chat/completions` 等子路径）
2. API Key 是否有效
3. 如果需要代理，代理地址是否正确且代理服务正在运行
4. 提供商的 API 服务是否正常

**Q：模型列表加载不出来？**
A：可能是提供商的 `/models` 接口返回了非标准格式。可以手动输入模型名称。

**Q：价格显示为 0？**
A：点击「刷新定价」尝试自动获取。如仍为 0，请手动输入价格。

### Prompt 配置

**Q：修改基线后 AI 生成质量没变化？**
A：基线有 60 秒缓存，修改后最多等 60 秒生效。也请检查修改的维度是否匹配您测试的项目属性。

**Q：模板变量替换后显示"未指定"？**
A：该变量对应的项目字段为空。请确保研发项目中填写了对应信息。

**Q：不小心改坏了基线/模板怎么办？**
A：点击「版本历史」找到之前的版本，一键回滚即可。

### 课程研发

**Q：AI 生成的课次方案质量不好？**
A：尝试以下方法：
1. 提供更详细的方向信息（特别是大致框架和核心诉求）
2. 使用修改意见功能针对性调整
3. 检查 Prompt 配置中的基线和模板是否完善
4. 考虑为生成动作配置更强的 AI 模型

**Q：封面图生成失败？**
A：检查 AI 服务配置中的图片动作是否已配置模型。

**Q：发布后教师看不到课程包？**
A：检查课程包状态是否为"已发布"。在课程包管理中确认状态。
