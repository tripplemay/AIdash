## 1. 注册与登录

### 首次使用（注册）

1. 向管理员索取**邀请码**
2. 在登录页底部点击「使用邀请码注册」
3. 填写邀请码、用户名（登录用，创建后不可修改）、姓名和密码（至少 6 位）
4. 点击「注册」，注册成功后用新账号登录

### 已有账号（登录）

1. 打开系统网址，进入登录页
2. 在「账号」栏输入您的用户名
3. 在「密码」栏输入密码
4. 点击「登录」按钮

登录成功后自动跳转到课程包列表页。

**如果登录失败**：页面会提示"账号或密码错误，请重试"。请检查用户名和密码是否正确。如仍无法登录，请联系管理员重置密码。

## 2. 浏览课程包

登录后进入**课程包列表页**，以卡片网格形式展示所有已发布的课程包。

每张课程包卡片展示：

- **封面图**：课程包主图
- **年龄段 · 难度**标签（右上角）
- **课程包名称**
- **课程概要**：适用年龄、第一课标题、本课成果
- **底部信息**：难度 · 时长 · 人数 · AI 回合数

点击卡片上的「进入详情」按钮，进入该课程包的详情页。

---

## 3. 筛选与搜索

### 按年龄段和难度筛选

在左侧边栏「课程包列表」下方，有一个可展开的**筛选树**：

1. 点击「课程包列表」菜单项，展开筛选树
2. 点击某个年龄段（如"A2｜8-9岁 基础段"），列表会筛选出该年龄段的课程包
3. 进一步点击年龄段下方的难度等级（如"中级"），可做二级筛选
4. 点击「全部课程」回到无筛选状态

筛选条件会自动记住，下次打开系统仍然保持。

### 搜索课程包

在页面中使用搜索功能，可按课程包名称进行模糊搜索。

## 4. 查看课程包详情

在课程包详情页，您可以了解课程包的完整信息：

### 课程包信息

- 封面大图
- 课程包名称和简介
- 四项元数据：适用年龄段、级别、状态、接入方式

### 课次列表

详情页下方列出该课程包的所有课次，每条课次展示：

- **课次编号和标题**：如"第 1 课《认识我的搭档》"
- **时长标签**：如"45 分钟"
- **人数和模式**：如"4-6 人线下小班"
- **AI 回合数**：如"3 个 AI 回合"
- **本课成果**：如"学生完成《我的搭档任务卡》"

**操作**：

- 课次右侧有「进入本课」按钮 → 点击进入单课授课页面
- 如果课次尚未接入内容，会显示灰色的"未接入"文字，无法点击

页面顶部有「← 返回课程包列表」链接，可返回列表页。

## 5. 进入单课授课

点击「进入本课」后，进入单课渲染页面。页面分为三个区域：

### 顶部导航栏

- 左侧：「← 返回课程包」链接 + 当前课次标题
- 右侧：「打印本课」按钮
- 最顶部：阅读进度条（随滚动实时更新）

### 左侧目录导航

页面左侧有一个固定的**目录导航面板**，列出本课所有教学环节（section）。

- 当前正在阅读的环节会自动高亮
- 点击任意环节标题可快速跳转到对应位置
- 滚动页面时，目录会自动跟踪阅读位置

### 右侧课程内容

课程内容按照教学环节依次展示。页面顶部是**课次信息卡**：

- 课次标签（如"互动设计"、"小组活动"）
- 课次标题和副标题
- 一句话目标
- 唯一核心成果
- 课次封面图（如有）

下方是各个教学环节，每个环节包含不同类型的内容块：

| 内容类型 | 说明 |
|---------|------|
| 文本段落 | 正文说明 |
| 引用块 | 带左边框装饰的引用内容 |
| 列表 | 有序或无序列表 |
| AI 对话模板 | 可一键复制的 AI 提示词模板 |
| 信息框 | 彩色高亮框（提示/成功/警告/危险） |
| 多列网格 | 2 或 3 列并排的信息框 |
| 折叠区域 | 可展开/折叠的内容，含时间标签 |
| 问答对 | 问题 + 答案格式 |

### 课次间导航

左侧边栏底部会显示当前课程包的所有课次列表：

- 格式："第 N 课 | 标题"
- 当前课次高亮显示
- 点击其他课次可直接跳转，无需返回详情页

## 6. 课堂辅助功能

### 一键复制 AI 模板

课程中的「AI 对话模板」块右上角有复制按钮（图标），点击即可将模板内容复制到剪贴板，方便在课堂中快速粘贴使用。

### 打印课程

1. 点击顶部导航栏右侧的「打印本课」按钮
2. 浏览器弹出打印对话框
3. 可以选择打印到纸张或保存为 PDF

打印时，系统会自动：
- 隐藏导航栏、进度条、复制按钮等界面元素
- 切换为单列白底排版
- 展开所有折叠区域

## 7. 问 AI 对话

点击左侧边栏的「问AI」进入对话页面。所有角色均可使用。

### 界面布局

页面分为左右两栏：
- **左侧对话列表**（280px）：显示所有对话，按最近更新排序
- **右侧对话区域**：消息展示 + 输入框

### 新建对话

1. 点击对话列表顶部的「新建对话」按钮
2. 弹窗中选择对话模式：
   - **通用模式**：通用 AI 助手，可以回答任何问题
   - **课程设计模式**：AI 具备课程设计专业知识，适合课程规划和设计咨询
3. 点击即创建对话并进入

### 发送消息

1. 在底部输入框中输入消息
2. 按 Enter 发送（Shift+Enter 换行）
3. AI 以流式方式实时输出回复，显示脉动蓝点表示正在生成
4. 生成期间输入框禁用，生成完毕后可继续对话

AI 回复支持 Markdown 格式，包括标题、列表、代码块、表格等。

### 联网搜索

AI 会自动判断是否需要联网搜索最新信息。搜索结果以 [1]、[2] 等引用标注展示在回答中，底部附来源链接，点击可查看原文。

### 复制 AI 回复

AI 回复消息右下角有「复制」按钮，点击可复制完整回复内容。

### 管理对话

- **切换对话**：点击左侧对话列表中的任意对话
- **对话标题**：首轮对话后 AI 自动生成标题（10 字以内）
- **删除对话**：点击对话项右侧的 × 按钮，3 秒内再次点击确认删除
- 对话列表中每条对话显示标题、模式标签（通用/课设）和更新时间

## 8. 个人资料

点击页面右上角的**头像**，选择「个人资料」进入资料页。

### 修改个人信息

- **姓名**：可修改
- **邮箱**（选填）：可修改
- **手机**（选填）：可修改
- **部门**（选填）：从下拉菜单选择
- **用户名**：创建后不可修改（只读显示）
- **角色**：由管理员分配（只读显示）

修改后点击「保存」。

### 更换头像

点击头像区域，从 **60 个预设卡通头像**中选择一个，点击即可更换。

### 修改密码

1. 在资料页点击「修改密码」按钮
2. 输入当前密码
3. 输入新密码（至少 6 位）
4. 确认新密码
5. 点击「确认修改」

### 退出登录

点击右上角头像 → 选择「退出登录」，返回登录页。

## 9. 常见问题

**Q：忘记密码怎么办？**
A：请联系管理员，管理员可以在后台为您重置密码。

**Q：课次显示"未接入"怎么办？**
A：该课次的内容尚未录入系统。请联系教学主管或管理员了解课程接入进度。

**Q：打印出来的内容排版不对？**
A：建议使用 Chrome 浏览器打印，并在打印设置中选择"A4"纸张大小。

**Q：筛选后看不到课程包了？**
A：可能是筛选条件太精确。点击侧边栏筛选树中的「全部课程」清除筛选条件。

**Q：问 AI 的"课程设计模式"和"通用模式"有什么区别？**
A：课程设计模式下，AI 会参考系统内置的课程设计基线知识来回答问题，更适合课程规划和教学设计相关咨询。通用模式则是普通的 AI 助手。

**Q：页面加载很慢？**
A：请检查网络连接。如持续缓慢，请联系管理员。
