# ADR-001：迁移至 Next.js 框架

> 状态：已确认
> 日期：2026-03-13

---

## 背景

项目初期以纯 HTML + 原生 JS 实现了原型落地（阶段一）。为支持真实后端逻辑（登录认证、数据库读写、课程包管理），需要迁移至全栈框架。

## 决策

| 议题 | 决策 | 理由 |
|------|------|------|
| 框架 | Next.js App Router | 全栈一体、文件即路由、SSR 支持、生态最大 |
| 样式 | Tailwind CSS + 现有 CSS 变量映射进主题 | 迁移平滑，视觉基线不漂移 |
| 后端方式 | Next.js API Routes 一体化 | 项目规模匹配，零额外配置，迭代最快 |
| 数据库 | 腾讯云 TDSQL-C PostgreSQL（Serverless） | 与服务器同厂商，内网互通延迟 <5ms，按量计费 |
| ORM | Prisma | 类型安全，与 Next.js 集成成熟 |
| 单课原型落点 | `window.open` 新标签，存放于 `/public/course-packages/` | 完全符合接入规范 v1，脱离系统可独立运行 |
| 样板课数据 | 保持原样，内容不变 | 冻结约束，不得替换 |

## 放弃的方案

- **Supabase**：无中国大陆节点，境外延迟不可控
- **Remix**：生态小于 Next.js，社区支持有限
- **前后端分离（React + Express）**：对此项目规模过重，维护成本高

## 影响

- 阶段一的 HTML 文件将被 React 组件替代
- CSS 变量体系延续，映射进 Tailwind 主题配置
- 接入规范 v1 不受影响，单课原型仍为独立 HTML
