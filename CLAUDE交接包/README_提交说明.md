# Claude 开发交接包说明

本目录用于把“教师授课系统开发”项目，完整提交给 Claude 启动开发。

## 目录结构
- `docs/`：项目说明、冻结项、UI/UX 基线、页面级说明、功能清单、验收清单
- `prompts/`：给 Claude 的主提示词、分阶段提示词、禁止事项、一次性启动提示词
- `assets/`：已确认视觉参考图、课程主题图、单课原型 HTML、当前系统原型
- `source_refs/`：已有规范与基础文档备份

## 推荐使用顺序
1. 阅读 `docs/01_项目总说明.md`
2. 阅读 `docs/02_开发冻结项与主链路.md`
3. 阅读 `docs/03_UIUX基线.md`
4. 阅读 `docs/04_页面级开发说明.md`
5. 阅读 `docs/08_验收清单.md`
6. 将 `prompts/01_Claude启动主提示词.md` 作为首次启动提示词提交给 Claude
7. 如需简化，可直接使用 `prompts/04_Claude一次性提交提示词_可直接粘贴.md`
8. 开发过程中按 `prompts/02_Claude分阶段开发提示词.md` 推进
9. 出现偏差时，用 `prompts/03_Claude禁止事项与偏差处理.md` 约束实现

## 重要说明
- 本交接包的文档、图片、原型、规范文件与 Trea 版本通用。
- 主要差异在于：`prompts/` 已改写为更适合 Claude 的阅读和执行方式。
- 若 Claude 的实现与交接包不一致，应以：已确认效果图 / 已确认最终图片 > 已确认原型 > 文档说明 为准。
