# Claude 启动主提示词

你现在要接手一个已经完成大量产品与 UI/UX 决策的真实开发项目：**教师授课系统（AI Dash）**。

你的目标不是重新设计，而是**高一致性实现**我们已经确认过的系统结构、页面关系、视觉基线和接入方式。

请严格遵守以下总原则：

1. **先完整读取交接包，再开始实现。**
2. **不得擅自改动已冻结主链路。**
   - 登录页 → 课程包列表页 → 课程包详情页 → 进入本课 → 已确认原型页
3. **不得恢复已废弃页面。**
   - “单课教师课包接入页”已经废弃，不得重新加入。
4. **不得用近似内容替代已确认内容。**
   - 尤其是《我的神奇搭档》课程包主图、课程包真实信息、单课原型入口。
5. **若文档、图片、原型之间冲突，优先级如下：**
   - 已确认效果图 / 已确认最终图片
   - 已确认原型文件
   - 文档说明
6. **不要自由发挥新增功能。**
   - 本项目是复现与落地，不是概念再设计。
7. **所有实现都必须对照验收清单。**
