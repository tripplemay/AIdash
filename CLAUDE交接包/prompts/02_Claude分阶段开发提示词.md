# Claude 分阶段开发提示词

## 阶段 1：项目初始化与页面壳
目标：先把页面骨架和主链路跑通。

要求：
- 建立登录页、课程包列表页、课程包详情页、已确认原型页、管理员后台页
- 不要加入“单课教师课包接入页”
- 先保证路由、跳转关系正确

## 阶段 2：登录页
目标：按已确认首页方案高一致性实现。

要求：
- 左侧品牌展陈，右侧登录窗口
- 账号 / 密码字段
- 企业微信 / 微信登录预留按钮
- 浅蓝紫雾光科技感
- 不得改成深色科幻风

## 阶段 3：课程包列表页
目标：按已确认效果图实现列表页。

要求：
- 左侧更窄、更轻、更紧凑
- 顶部系统导航存在
- 右侧主内容为课程包列表
- 第一个课程包为《我的神奇搭档课程包》真实内容
- 首卡图片与样板课信息一致

## 阶段 4：课程包详情页
目标：实现课程包详情页并绑定真实样板课信息。

要求：
- 课程包信息正确
- 课次列表正确
- 详情主图必须使用已确认最终图，不得近似替代
- “进入本课”按钮指向已确认原型页

## 阶段 5：已确认原型页接入
目标：承载《我的神奇搭档》已确认原型内容。

要求：
- 作为“进入本课”后的直接落点
- 不新增中间页
- 若技术上需要嵌入，应保证不破坏主链路与可用性

## 阶段 6：管理员后台
目标：实现课程包与课次管理界面。

要求：
- 维护课程包元信息
- 维护课次元信息
- 绑定 index.html / assets/ / attachments/ / lesson.json
- 保存、发布、下线类操作

## 阶段 7：逐项验收
目标：对照验收清单输出结果。

要求：
- 列出通过项
- 列出未通过项
- 列出偏差项
- 若有偏差，说明原因与修正建议
