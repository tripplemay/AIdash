# UI/UX 基线

## 总体气质
已确认的系统视觉基调为：
**浅蓝紫雾光科技感**

关键词：
- 高亮度
- 轻科技
- 通透
- 教师友好
- 柔和圆角
- 半透明浅色卡片
- 浅蓝 / 浅紫渐变雾光
- 不走深色科幻
- 不走厚重企业后台风

## 首页（登录页）基线
已选定方案：品牌展陈型 + 浅蓝紫雾光科技感

要求：
- 左侧：品牌介绍、系统定位、主视觉
- 右侧：登录窗口
- 保持清晰、可信、未来感但不压迫
- 科技感来源于轻发光、通透渐变、漂浮几何元素，不依赖深色背景

## 列表页基线
- 延续首页风格
- 左侧导航更精致、更窄、更紧凑
- 页面整体轻、亮、清晰
- 卡片需更像真实教育产品，而不是占位框

## 详情页基线
- 维持系统统一公有壳层
- 通过课程主图和轻主题气氛体现课程独特性
- 不要把课程详情页做成另一套完全不同的网站

## 禁止项
- 深蓝黑底宇宙风
- 过强霓虹夜景感
- 游戏 UI 风过重
- 左侧侧栏过厚过宽
- 间距过松，导致页面像占位稿
