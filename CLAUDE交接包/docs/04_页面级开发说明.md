# 页面级开发说明

## 1. 登录页
### 目标
作为系统首页，承担品牌展陈与登录入口功能。

### 结构
- 左侧：品牌区
  - AI Dash logo
  - “教师授课系统”标题
  - 系统一句话价值说明
  - 主视觉插画 / 机器人科技图
- 右侧：登录卡
  - 账号
  - 密码
  - 登录按钮
  - 忘记密码
  - 企业微信登录（预留）
  - 微信登录（预留）

### 行为
点击登录后进入课程包列表页。

## 2. 课程包列表页
### 目标
让老师快速浏览课程包。

### 左侧
- 品牌区
- 老师信息卡
- 导航菜单
- “课程包”菜单可展开
- 展开项：年龄段 → 级别

### 右侧
- 页面标题
- 搜索 / 筛选
- 课程包卡片列表
- 分页区

### 当前真实卡片
第一个课程包必须是《我的神奇搭档课程包》。

## 3. 课程包详情页
### 目标
展示课程包信息与课次列表。

### 内容
- 课程包主图
- 课程包基本信息
- 适用年龄
- 级别
- 状态
- 课次列表
- 第 1 课“进入本课”按钮

### 重要约束
主图必须严格使用已确认版本：
- 蓝色大机器人
- 绿色小机器人
- 一个男孩握手互动
- 左上带“样板课”标识
- 标题为“我的神奇搭档课程包”

## 4. 已确认原型页
### 目标
承载已接入的单课原型内容。

### 当前状态
- 作为“进入本课”后的直接落点
- 直接展示《我的神奇搭档》已确认原型内容
- 不再使用中间接入页

## 5. 管理员后台页
### 目标
管理课程包与课次接入。

### 内容
- 课程包元信息维护
- 课次元信息维护
- 绑定单课入口文件
- 绑定资源目录
- 绑定附件目录
- 发布 / 保存 / 下线类操作
