# 项目总说明

## 项目名称
教师授课系统（AI Dash）

## 项目目标
开发一个面向老师与管理员的教师授课系统，用于：
- 统一管理课程包
- 让老师从系统中进入具体课程
- 承载按规范接入的单课教师课包内容
- 为后续更多课程包、更多课次提供稳定接入与管理能力

## 当前开发窗口范围
本窗口仅讨论并推进：
- 教师授课系统开发
- 页面结构
- UI/UX
- 单课接入方式
- 管理端维护链路

明确不混入：
- 课程内容设计讨论
- 教学法延展讨论

## 用户角色
### 老师
- 登录系统
- 浏览课程包
- 查看课程包详情
- 进入本课
- 打开已接入的教师课包原型 / 成品页

### 管理员
- 维护课程包元信息
- 维护课次元信息
- 上传 / 绑定单课成品包
- 控制发布状态

## 当前样板课程包
《我的神奇搭档课程包》
- 适用年龄：8–12 岁
- 第 1 课：《我的神奇搭档》
- 本课成果：《我的神奇搭档介绍页》
- L1
- 45 分钟
- 4–6 人线下小班
- 3 个 AI 回合
- 已按规范接入
